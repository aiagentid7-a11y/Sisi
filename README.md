# Sisi AI — Story Collage Studio

Repository dokumentasi karakter AI pribadi **Sisi** dan alur cerita kolase fotonya.

## Referensi utama
- **Wajah utama:** gambar referensi pengguna `Screenshot_20261009-120401.png`.
- **Ekspresi tambahan:** kolase 16 ekspresi yang disetujui pengguna.
- **Penting:** jangan mengambil wajah dari hasil kolase lama yang tidak mirip.
- File gambar referensi belum disimpan di repository ini. Unggah hanya jika pengguna mengizinkan, idealnya setelah repository dibuat private.

## Cara menggunakan
1. Baca [SKILL.md](SKILL.md) untuk aturan wajah.
2. Baca [MEMORY.md](MEMORY.md) untuk keputusan pengguna.
3. Baca [stories/BEACH_HOLIDAY.md](stories/BEACH_HOLIDAY.md) untuk sembilan part.
4. Sebelum membuat gambar, sertakan **gambar referensi utama** sebagai input visual. Instruksi teks saja tidak menjamin wajah identik.
5. Hasilkan 9 foto berurutan per part; tinjau kemiripan wajah sebelum lanjut ke part berikutnya.
